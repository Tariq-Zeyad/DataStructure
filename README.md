#  Data Structure

## 📌 Project Overview
This project is a Java-based application designed to demonstrate the practical implementation of different **Data Structures** concepts within a complete integrated system.

The project combines multiple classes that work together as one application to improve:
- Data organization
- Searching efficiency
- Process management
- System performance

The project also contains several educational explanations and examples inside the `src` folder to help students better understand how each data structure works and how the classes interact together inside one complete system.

---

Data Structures are considered one of the most important foundations in computer science and software engineering.

- Organize data efficiently

# 🧩 Project Structure

The project contains several interconnected Java classes, where each class is responsible for a specific functionality within the system.

## 📂 Main Classes

### 🔹 `FinalProject.java`
The main entry point (**Entry Point**) of the system.

Responsibilities:
- Contains the `main()` method
- Controls the execution flow
- Connects all classes together

---

### 🔹 `AdminBinaryTree.java`
Implements the **Binary Tree** Data Structure.

Used for:
- Organizing data
- Fast searching
- Efficient administration management

---

### 🔹 `ArrayBag.java`
Implements the **Bag Data Structure**.

Used for:
- Storing collections of data
- Managing grouped elements
- Handling unordered data efficiently

---

### 🔹 `Customer.java`
Represents the **Customer Entity** inside the system.

Used for:
- Storing customer information
- Managing customer-related data

---

### 🔹 `User.java`
Represents the **User Entity**.

Used for:
- Managing user information
- Handling user interactions within the system

---

### 🔹 `Queue.java`
Implements the **Queue Data Structure** using the FIFO principle  
(**First In, First Out**).

Used for:
- Managing requests
- Organizing processing order
- Simulating waiting systems

---

### 🔹 `Stack.java`
Implements the **Stack Data Structure** using the LIFO principle  
(**Last In, First Out**).

Used for:
- Managing history operations
- Undo/Redo functionality
- Temporary process tracking

# ⚙️ Setup Requirements

## 📁 Folder Structure

Place all `.java` files inside a folder named:

```text
src/
```

Example:

```text
project-folder/
│
└── src/
    ├── FinalProject.java
    ├── AdminBinaryTree.java
    ├── ArrayBag.java
    ├── Customer.java
    ├── User.java
    ├── Queue.java
    ├── Stack.java
```

---

# 💻 Running the Project

1. Open the project folder in your IDE.
2. Ensure all `.java` files are inside `src`.
3. Run:

```text
FinalProject.java
```

This file contains the `main()` method and serves as the starting point of the system.
